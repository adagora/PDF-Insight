Proxy between the PDF Insight web app and Google Gemini. Receives locally inspected text from PDFs, OCR and attachments; binary images are rejected. Returns a validated summary and structured data (brief §04). Generated from the Zod schemas — do not edit by hand (ADR-0006).

| Status | Description | Body |
|---|---|---|

### `POST /v1/analyze` — Summarise a document and extract structured data

Validates the whole text-only request, redacts credentials, detects prompt-injection attempts, then asks Gemini for a schema-constrained extraction (retry once on an invalid answer). Gemini authentication uses only the Worker secret; clients provide no credentials. Binary images are rejected. Amounts and dates are grounded against source text, including local OCR. Limits: body ≤ 8388608 bytes, ≤ 500 pages, ≤ 480000 characters.

**Request body** (`application/json`): [AnalyzeRequest](#analyzerequest)
